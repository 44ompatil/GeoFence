# GeoFence Frontend

This React + Tailwind dashboard is designed for monitoring an animal collar geofence system.

## Scripts

```bash
npm install
npm run dev
```

## Firebase setup

1. Copy `.env.example` to `.env` at the project root or set environment variables in your hosting environment.
2. Update the Firebase configuration values with your project details.
3. Run `firebase login` and `firebase init` if deploying to Firebase Hosting.

## Production build

```bash
npm run build
```
